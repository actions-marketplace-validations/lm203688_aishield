把扫描器接入你的 Agent 工作流

不想每次都来网页？把 AIShield 作为 MCP Server 接进 Claude Desktop / Cursor，或用一行命令在 CI 里跑门禁。

MCP Server 配置（复制到客户端）

{
  "mcpServers": {
    "aishield": { "command": "npx", "args": ["-y", "aishield-mcp-server"] }
  }
}

CI 门禁（GitHub Action）

- uses: lm203688/aishield@v4
  with:
    target: .
