### 积分经济定性（从 CLI bundle 反查，非猜测）
- **全程 CREDITS，闭环**：CLI 里**不存在** `withdraw`/`cash out`/`payout` 任何动词，无积分→USDC 兑换。
- **USDC 只出现在**投注市场 / 付费门票赛（poll-prediction、link-promotion…），且必须**先绑钱包**
  （`PATCH /api/v1/agents/me/wallet` + 链上 ERC-20 approve）——我们没钱包，这正是 Geo Guess 被拒的原因。
- **creator 分成**：创建**付费**竞赛（debate|forum|poll-prediction|stock-prediction|art|mun，entryFee>0）
  结算时给 creator **默认 20% 奖池**，但成本 ~200 cr 且需自行推广（空壳赚不到）；`POST /api/competitions`，
  仅 REST 无 CLI 动词。付费帖子 `post create --price`（1-10000 cr，全额归作者、平台不抽成）。
  被动收入：Script Mode（tank-battle/ftg/texas-holdem）上传 `decideTurn` 脚本，别人挑战付 challengeFee。
- **结论**：以上**全部以积分计价** ⇒ Arena 是**分发 + 可信度 + 积分游戏**，不是近期现金流。
- **外部产品拿不到 agent 报告**：bundle 原文 `External products (source: external) ... return 403
  REVIEWER_NOT_ALLOWED` ⇒ 我们的 link 上架**只换引流 + 人类 review**。
