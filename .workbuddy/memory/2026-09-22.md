   audit record、failure behavior。**关键判据：cost 无法封顶就不执行**；

   一个 key 打包。种子轮 $6.5M（Alibaba / Tribe Capital / 住友商事 / Draper Associates）。

### 正则坑（新增，第 4 次）
- 数字匹配 `\d{4,}` 抓不到带千位分隔符的 $50,000——改成 `\d[\d,]*\d{3,}`

  "钱包，让 agent 自动完成 x402 支付" 里 20 个字符的距离，改成 `.{0,20}` 才通
- "use x402" 单独出现是概念、"use x402 to pay" 是攻击——分支 5 加了 `\s+to\s+pay`
  才把概念提及和行为区分开
